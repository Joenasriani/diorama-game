# DIORAMA

**Historical name:** Tiny Diorama Robot  
**Status:** original isometric spatial puzzle game  
**Play:** https://joenasr.itch.io/diorama  
**Creator:** Joe Nasr  
**Creator identity:** https://joe-nasr-signals.vercel.app/v2/

DIORAMA is a 3D puzzle game built around compact architectural scenes, route logic, switches, bridges, lifts and spatial planning.

The player studies each miniature structure, moves through reachable paths, activates mechanisms and reconstructs a valid route to the goal.

Tiny Diorama Robot and DIORAMA refer to the same game lineage.

This repository is the public source repository for DIORAMA. Existing branches and historical files are retained as development history.
