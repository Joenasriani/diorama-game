# DIORAMA – دليل باللغة العربية

**DIORAMA** لعبة ألغاز ميكانيكية ثلاثية الأبعاد تعمل مباشرة في المتصفح. وجّه روبوتًا صغيرًا عبر عوالم مصغّرة، واستخدم الجسور والمصاعد والمفاتيح والبوابات للوصول إلى الهدف.

## العب الآن
- [صفحة اللعبة على itch.io](https://joenasr.itch.io/diorama)
- [نسخة المتصفح](https://diorama-game.vercel.app)

## المشروع والمساهمة
تحتوي نسخة مستودع GitHub على **25 مستوى**. توجد بيانات المستويات ومحرك Three.js داخل ملف `index.html`، ولا تحتاج إلى عملية بناء. يختلف عدد المستويات المعلن عنه في itch.io عن العدد الموجود هنا.

يمكنك اقتراح مستويات جديدة، والإبلاغ عن الأخطاء القابلة لإعادة الإنتاج، وتحسين التحكم باللمس وإمكانية الوصول. راجع [دليل المساهمة](../../CONTRIBUTING.md) و[وثيقة تصميم المستويات](../LEVEL_AUTHORING.md). لم تُنفّذ بعد ميزة استيراد حزم مستويات مستقلة، ولا يعني نجاح الاختبار البنيوي أن اللغز قابل للحل.

## التشغيل محليًا
```sh
python3 -m http.server 8080
```
ثم افتح `http://localhost:8080/`.
