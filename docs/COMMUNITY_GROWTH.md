# Authentic GitHub adoption – measurement plan

The objective is **relevant developers, valid forks, useful PRs, real adoption, and maintainability**, not inflated counters.

## Discovery funnel

Public search / community demonstration → accurate repository overview → play the real game → inspect developer documentation → star / fork / propose a level / report an issue → reviewed contribution → repeat participation.

## Track monthly

| Metric | Interpretation | Caveat |
| --- | --- | --- |
| Stars and new stars | Interest / bookmarking | Not equivalent to adoption |
| Forks | Potential reuse or experimentation | Not every fork is active |
| External issues | Real reports and proposals | Count reproducible or useful reports separately |
| External pull requests | Developer effort | Track reviewed/merged contributions |
| Accepted level proposals | Expansion interest | Do not call them playable levels before implementation |
| Release activity | Evidence of maintained project | Must match source and advertised build |
| External references | Organic discovery | Verify actual relevance |
| Returning contributors | Sustainable participation | Avoid collecting private personal data |

## Review routine

Compare the current month with the preceding month. Record source/date, outcomes, and material limitations. Separate repository traffic from game plays; GitHub insights may expose limited historical windows and analytics cannot prove downstream adoption by themselves.

## Ethical visibility

Share genuine gameplay captures, technical explanations, specific extension opportunities and verified release notes in communities where they are relevant. Do not buy stars, create synthetic contributions, mass-post promotional links, or represent an unimplemented editor/plugin system as already available.

## Maintenance policy

Mark easy documentation and reproduction issues as possible starting points, but do not promise that runtime feature requests are `good first issue` without reviewing complexity. Keep discussions and issues respectful and focused on real improvements.
